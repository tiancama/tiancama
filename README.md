### 🛠️ What I Build

Most of my projects share one foundation: **Nodeheim**, a platform-agnostic graph engine in C#.

- **Nodeheim** *(in progress)*: the engine itself, a graph of nodes traversed by agents, with hexagonal architecture, an Avalonia editor and a versioned JSON/XML document format.
- **Nodeheim Conquest** *(planned)*: a real-time node-capture game, built as a fork to explore agentic development.
- **Agent simulation** *(planned)*: agents that explore a Nodeheim world and learn how to act through reinforcement learning.
- **Nodeheim Tales** *(planned)*: a web application for interactive storytelling, built on Nodeheim.
- **Finance tool** *(planned)*: income, expenses, accruals and imported bank statements, with a strong focus on data security.

### 🤖 How I Work with AI

I treat AI-assisted development as something to explore, not just to use. I try different approaches on purpose:

- **AI pair programming** in Nodeheim: I write the code; AI acts as navigator, reviewer and research partner.
- **Agentic engineering** in Nodeheim Conquest: an AI agent writes the code; I plan, specify and review.
- **Vibe coding** *(planned)*: a larger project built without reading the code, to see how far that gets.

Comparing these approaches shows me where each one works, where it fails, and what it takes to keep ownership of design and quality.
